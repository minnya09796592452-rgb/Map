transform_trace.py — purpose and observed behavior:
1. Receives the Assembly-CSharp.dll path through sys.argv[1].
2. Opens the .NET PE/metadata using dnfile.dnPE(dll).
3. Reads raw DLL bytes.
4. Resolves MethodDef rows by RID.
5. Converts a method RVA to a file offset using pe.get_offset_from_rva().
6. Parses Tiny/Fat method headers to determine IL start and IL size.
7. Decodes IL opcodes using a one-byte operand-length table.
8. Resolves metadata tokens for:
   - 0x06: MethodDef
   - 0x0A: MemberRef
   - 0x04: Field
   - 0x70: UserString
   - 0x2B: MethodSpec
9. Decodes branch target offsets.
10. Writes the trace to transform_trace.txt.
